# 경로 탐색 — A\* / JPS 소스 코드

격자 위 최단 경로 탐색을 라이브러리 없이 직접 구현했습니다. (1인 구현)

| 경로 | 내용 |
|---|---|
| `AStar/main.cpp` | A\* 구현 — 우선순위 큐 기반 개방/폐쇄 목록 운용, 휴리스틱 계산, 경로 역추적, Win32 시각화 |
| `JPS/JPS.h` · `JPS.cpp` | JPS(Jump Point Search) 핵심 — 직선·대각 점프 규칙, 강제 이웃(forced neighbor) 판정, 분기점 평가 |
| `JPS/Render.h` · `Render.cpp` | 탐색 과정 시각화 — 점프 규칙이 깨지는 케이스를 눈으로 확인하기 위해 직접 구현 |
| `JPS/main.cpp` | Win32 진입점 · 맵 편집 · 탐색 실행 |

## 왜 JPS인가

A\*는 개방된 격자에서 대칭적인 중복 경로를 전부 평가하느라 탐색 노드가 폭발합니다.
JPS는 직선·대각 방향으로 '점프'하며 **분기점만 평가**해 이 중복을 가지치기합니다.

## 구현하며 막혔던 지점

강제 이웃 판정과 점프 규칙이 **격자 경계와 장애물 모서리에서** 자주 어긋났습니다.
규칙이 조금만 틀려도 경로가 장애물을 뚫거나 최단이 아닌 경로가 나오는데,
어느 케이스에서 깨지는지가 로그로는 보이지 않았습니다.

그래서 탐색 과정을 화면에 직접 그려(`Render.cpp`) 확장 노드와 점프 지점을 눈으로 확인하며
케이스를 하나씩 잡았습니다.

> **빌드 안내** — Win32 데스크톱 애플리케이션으로, 시각화를 포함해 Visual Studio에서 빌드합니다.
> 프로젝트 파일(`.sln`/`.vcxproj`)과 리소스는 저장소에서 제외했으며, 이 저장소는 코드 열람 목적입니다.
